# TUXEDO Control Center - Enhanced

This is an enhanced fork of TUXEDO Control Center with additional features:

## New Features
- **Keyboard Backlight Animations**: Breathing and wave effects for RGB keyboards
- **Memory Optimization**: Lazy-loading GUI reduces memory footprint when using tray mode
- **Chinese Support**: Full zh-CN language localization
